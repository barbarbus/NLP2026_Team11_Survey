# NLP2026 Team 11 — Hallucination Evaluation Survey

This repository contains the course proposal and a reading corpus for a survey of large language model hallucination evaluation methods.

- [124-paper catalogue](Hallucination_Evaluation_Library/paper_catalog.csv): 16 core and 108 important papers, with bibliographic metadata, local PDF paths, code links, and verification status.
- [Paper PDFs](Hallucination_Evaluation_Library/papers): the 124 locally collected papers, organized by core/important status.
- [Source-code archives](Hallucination_Evaluation_Library/code): locally collected code where available; see the catalogue for original URLs.
- [Complete taxonomy and classification rules](Reading_Notes/Taxonomy_124.md)
- [Machine-readable per-paper classification](Reading_Notes/Taxonomy_124.csv)
- [Detailed reading notes](Reading_Notes/notes) and [research map](Reading_Notes/Research_Map_Reviewed.md)
- [Proposal](proposal/Team11_Proposal.pdf)

The taxonomy separates a paper's research role from its primary evaluation method, optional secondary methods, and evaluation target. A benchmark or survey is not counted as a new method merely because it uses one.

The papers and source archives remain the works of their respective authors. Bibliographic and original source links are recorded in the catalogue.
