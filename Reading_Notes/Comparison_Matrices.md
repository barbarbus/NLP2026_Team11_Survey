# 幻觉评价方法与基准：可比条件矩阵（第一版）

本矩阵服务计划书 RQ2–RQ3。它不是跨论文排行榜：不同研究的评价对象、数据构造、金标粒度和模型版本均可能不同。文中“适用”指该研究实际支持的评价设置，不表示已经在所有领域验证。每项以本组精读笔记为证据入口，正式报告引用数值仍须回到论文表格。

## 矩阵 A：代表性评价方法

**阅读列：评价对象｜判断单位｜所需信息与机制｜已有验证｜关键限制。** 同列内容可横向比较；缺失的公开验证不能当作负面实验结果。

### H 人工评价

- **[C14 人工评价综述](notes/core/C14_Human_Evaluation_Survey.md)**｜跨任务的“幻觉”人工定义与标注协议｜标注单位和参考材料随研究而异｜整理现有研究的人评设计｜提醒检查定义、标注者、分歧处理与报告透明度｜其本身是综述，不能当作单一人工金标或统一人机相关数值。
- **[I037 SummEval](notes/important/I037_SummEval.md)**｜摘要一致性与其他质量维度｜摘要级人评分｜专家/非专家评分并用于指标元评估｜提供人类评价参照｜四个质量维度不能都当幻觉标签；系统级与实例级相关不同，评分二值化会改变结论。

### E 参考或证据核验

- **[C07 FActScore](notes/core/C07_FActScore.md)**｜指定知识源下的长文本事实精确率｜原子事实，并对已作答样本做平均｜事实分解、限制范围检索与自动支持判断｜有人评事实标签和模型级误差比较｜无证据不等于客观错误；整体分数误差小不保证逐事实检测准；需同时报告拒答率和事实数量。
- **[I042 FEQA](notes/important/I042_FEQA.md)**｜摘要相对源文的忠实性｜由摘要生成的问题及源文答案｜QA 双侧匹配｜用摘要人评进行元评估｜问不出的问题不会被核验；问答部件质量会进入最终分数。
- **[I062 QAGS](notes/important/I062_QAGS.md)**｜摘要相对源文的事实一致性｜问题及两侧答案｜从摘要与源文答题后比较｜有摘要人工判断｜参考文本和问题生成策略改变证据覆盖；不能将未提问的事实视作已验证。
- **[I086 QAFactEval](notes/important/I086_QAFactEval.md)**｜摘要的来源一致性｜问题、可答性及答案匹配｜优化 QA 部件并融合相关模型｜在多个人评基准比较｜部件与基准版本对结果敏感，需在相同样本和输入权限下比较。
- **[I043 QuestEval](notes/important/I043_QuestEval.md)**｜摘要事实性与内容覆盖｜双向问答｜源文和生成文本分别发问｜有人评相关性比较｜精确率与召回率目标不同；重要性权重和聚合公式必须写清。
- **[I057 RAGAs](notes/important/I057_RAGAs.md)**｜RAG 的答案忠实性、相关性及上下文质量｜声明/问题/上下文片段｜多种 LLM 驱动的分解与判断｜以组件指标评价系统｜各维度不能合并解释成“幻觉率”；LLM 裁判、提示与版本带来成本和漂移。
- **[I032 FacTool](notes/important/I032_FACTOOL.md)**｜多任务生成内容的事实核验｜拆出的声明｜外部工具检索与核验｜覆盖若干生成任务｜工具证据质量、任务专用步骤和调用成本决定适用范围。

### T 判别器、蕴含与内部表征

- **[C09 AlignScore](notes/core/C09_AlignScore.md)**｜输入与生成文本的语义对齐｜文本块与聚合结果｜多任务监督训练的对齐函数｜跨事实一致性任务元评估｜高分是与输入一致，不自动证明世界事实正确；分块、聚合及训练测试重叠要检查。
- **[I073 FactCC](notes/important/I073_FactCC.md)**｜摘要与源文的一致性｜句/片段及整体预测｜合成错误训练的判别器｜有人工标注摘要测试｜合成负例可能留下词面捷径；原版与后续资源版本要区分。
- **[I092 SummaC](notes/important/I092_SummaC.md)**｜摘要来源一致性｜NLI 句对分数再汇总｜对现成 NLI 做输入拆分与聚合｜在多个数据集元评估｜聚合可稀释局部错误；NLI 训练数据与基准重叠需审计。
- **[I044 ARES](notes/important/I044_ARES.md)**｜RAG 的上下文相关、答案相关和忠实性｜系统总体估计及样本裁判｜合成训练的轻量裁判＋少量人工标签校正｜报告跨域/系统级实验｜总体估计的统计保证有抽样条件，不等于逐样本检测保证；模拟 RAG 与真实 RAG 分开解读。
- **[I095 TrueTeacher](notes/important/I095_TrueTeacher.md)**｜摘要来源一致性｜摘要/来源对｜LLM 生成监督标签并蒸馏学生｜比较跨域和多语迁移｜教师标签噪声与生成器分布可能传给学生；训练与测试来源要隔离。
- **[I090 Semantic Entropy Probes](notes/important/I090_Semantic_Entropy_Probes.md)**｜语义熵代理的错误风险｜一次回答的隐藏状态｜用多次采样语义熵作教师训练探针｜比较采样成本与检测质量｜推理成本低不代表训练成本消失；需白盒状态访问，教师标签也有误差。

### U 自一致性与不确定性

- **[C08 SelfCheckGPT](notes/core/C08_SelfCheckGPT.md)**｜无外部证据时的生成不稳定性｜句子及多次采样回答｜比较样本间的一致性，可借助 NLI/LLM｜有人工标注的长文本评估｜稳定而错误的回答可能漏检；采样和辅助裁判成本不能忽略。
- **[C10 语义熵](notes/core/C10_Semantic_Entropy.md)**｜多种合理表述背后的语义不确定性｜语义等价类/回答｜重复采样、语义聚类和熵｜在 QA 等任务分析风险覆盖｜语义聚类依赖辅助模型；低熵不等于事实正确，长文本需局部化。
- **[I083 P(True)/P(IK)](notes/important/I083_PTrue_PIK.md)**｜候选答案正确的自评与回答前可知性｜候选/问题｜模型自报概率及校准｜检查正确性预测｜“知道自己知道”受提示、选项、模型及域外分布影响。
- **[I075 Generating with Confidence](notes/important/I075_Generating_with_Confidence.md)**｜黑盒回答置信与选择性回答｜多次采样的答案关系｜语义图/谱等统计｜评估风险覆盖及校准｜多采样预算、语义相似度和阈值决定结果；不能仅以排序性能代替校准。

### J LLM 裁判

- **[I100 G-Eval](notes/important/I100_G_Eval.md)**｜摘要等 NLG 的多维质量评分｜单回答/维度分数｜评分步骤提示和生成概率加权｜与人评分相关性比较｜整体质量维度不全等于幻觉；解析失败、模型偏好和历史 API 版本影响重现。
- **[I065 ChatGPT Factual Inconsistency Evaluator](notes/important/I065_ChatGPT_Factual_Inconsistency.md)**｜摘要事实不一致｜输入/摘要对｜提示式 ChatGPT 判断｜与摘要人评比较｜提示、输出解析、A/B 位置和解释错误会影响结论。
- **[I097 ChainPoll](notes/important/I097_ChainPoll.md)**｜生成回答事实错误｜声明/回答｜多次 LLM 投票或链式判断｜报告检测效果｜投票次数同时改变成本和准确率；裁判间错误相关不能当作独立重复。
- **[I104 LM vs LM](notes/important/I104_LM_vs_LM.md)**｜声明的事实错误｜动态交叉询问后的声明｜另一模型提出追问并据矛盾判断｜黑盒测试｜矛盾只证明说法不相容，未必识别哪句为假；追问与投票预算需对齐。

## 矩阵 B：代表性基准与元评估资源

**阅读列：构念｜样本/标注单位｜金标或参照｜适合检验的能力｜主要可比性限制。**

- **[C05 TruthfulQA](notes/core/C05_TruthfulQA.md)**｜人类常见错误观念诱发的真实性｜问题与回答｜参考答案及人工/训练裁判｜开放域世界知识与拒答｜不是所有任务的幻觉率；真实性与信息性须分开报告。
- **[C06 HaluEval](notes/core/C06_HaluEval.md)**｜多任务生成中的幻觉识别｜问答/对话/摘要等实例｜合成候选加人工标注｜识别有意构造的错误｜合成分布与自然错误分布不同；答案格式和选项选择会形成捷径。
- **[C11 TRUE](notes/core/C11_TRUE.md)**｜给定 grounding 的事实一致性｜统一二元样本｜11 个来源异质的数据集标签映射｜样本级 AUROC 元评估｜原标签的“矛盾”“无证”“不完整”被合并；跨集平均不能说明每个场景都胜出。
- **[C12 RAGTruth](notes/core/C12_RAGTruth.md)**｜RAG 输出相对提供材料的忠实性｜字符跨度和回答｜人工细粒度标注｜定位、检测和风险覆盖｜文本真实但材料未支持仍可算不忠实；跨度与回答级指标不可混用。
- **[C13 FELM](notes/core/C13_FELM.md)**｜开放生成的细粒度事实性｜segment 与 atomic claim｜人工/参考核验｜多领域评价器能力｜segment 和 claim 的分母不同；金标参考版本与未知信息映射需明确。
- **[I007 FRANK](notes/important/I007_FRANK.md)**｜摘要事实错误类型与指标元评估｜摘要/句子/错误类别｜人工错误标注｜对比摘要指标｜生成器、数据集和错误类型混杂；版本与标签修订要核查。
- **[I037 SummEval](notes/important/I037_SummEval.md)**｜摘要质量四维评分｜摘要级多维人评分｜专家和非专家｜人机一致性参照｜“一致性”之外的维度不能当事实标签；系统/实例层级分开。
- **[I013 HALoGEN](notes/important/I013_HALoGEN.md)**｜跨领域生成事实与拒答｜每回答原子事实｜程序、索引与模型核验｜跨任务泛化｜核验器覆盖和空原子分母影响得分；引用存在不等于引用支持。
- **[I014 HalluLens](notes/important/I014_HalluLens.md)**｜训练语料/输入一致性与动态外部事实｜问题/回答｜动态金标及裁判｜更新知识与拒答｜动态题、裁判提示和知识截止的版本漂移需记录。
- **[I111 HalOmi](notes/important/I111_HalOmi_Multilingual_MT.md)**｜多语言机器翻译中的幻觉与遗漏｜细粒度人工标注｜源句和译文｜跨语言迁移与遗漏区别｜其“幻觉”含与源文脱离，不能直接等同开放域问答世界事实错误。
- **[I115 Med-HALT](notes/important/I115_Med_HALT.md)**｜医学错误建议、不可答和文献记忆｜医学 QA/任务实例｜任务真值及拒答条件｜专业域压力测试｜拒答策略、标识符正确性和医学风险不能压成单一准确率。

## 跨论文结论与报告写法

1. **RQ1：先限定参照。** 世界事实正确性、给定来源忠实性、答案完整性和语用适切性是不同目标。[C07](notes/core/C07_FActScore.md)、[C11](notes/core/C11_TRUE.md)、[I041](notes/important/I041_Correctness_and_Faithfulness_QA.md)给出可直接对照的边界案例。最终报告的每个结果必须写清参照对象和判断单位。
2. **RQ2：按证据链比较。** E/T 通常依赖外部来源或训练数据；U 可以无外部检索，但无法可靠排除稳定错答；J 灵活却引入裁判偏差。混合方法应拆成分解、证据获取、判断、聚合四步，成本与错误也逐步传播。
3. **RQ3：人机一致性须同口径。** 系统级相关、样本级 AUROC、跨度级 F1、人工一致率和校准误差服务不同决策。不能把不同论文表中的最高值排成统一榜单。比较时控制样本、生成器、裁判版本、预算和标签映射。
4. **实用选择。** 来源明确的摘要/RAG 优先核对来源忠实性和证据覆盖；开放域长回答可用原子事实核验并报告拒答和信息量；无法取外部证据时，自一致性是风险筛查而不是事实证明；高风险领域应保留人工复核和错误成本分析。
