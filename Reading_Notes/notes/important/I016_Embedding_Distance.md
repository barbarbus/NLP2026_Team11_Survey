# I016 关键词嵌入距离检测：模型身份与“幻觉”标签混淆的实例

## 来源和阅读范围

Emanuele Ricco、Lorenzo Cima、Roberto Di Pietro，*[Hallucination Detection: A Probabilistic Framework Using Embeddings Distance Analysis](https://arxiv.org/abs/2502.08663)*，arXiv:2502.08663v1，2025-02-10。本地22页PDF：第1–8页全部实质正文、第11–22页问题清单、标注样例、KDE公式、完整训练KL/距离表及三种范数测试表均已逐页阅读；第9–10页参考文献用于定位。目视核对第3页构造、第4页公式、第6页测试主表、第7页跨方法比较、第13页**真实/幻觉样例**以及第21–22页完整测试表。论文未给可固定的本地源码/原始生成数据入口，本次没有重跑模型；下文对样例和设计的审计是**独立分析**，不是复现实验。

## 一、论文想证明什么，以及实际标签是什么（PDF1–3）

作者希望用“幻觉文本和非幻觉文本在嵌入空间距离分布不同”建立检测器。核心数据构造：问GPT-4设计64个关于2022-09至2023-09时段的问题，分别给Llama-2-7B与Llama-3.1-8B多次采样；根据作者所写训练截止时间，**把所有Llama-2答案标为幻觉，把所有Llama-3.1答案标为非幻觉**。没有对任一回答逐条事实标注，也没有列出“该模型实际知道/不知道此事实”的核验。其实际监督目标是**生成模型身份与训练截止标签**，与回答真假完全重合；即便分类准确，也无法从现有设置识别距离差异来自真假、模型风格、训练语料、模型规模、量化误差或采样。论文自己限制节承认Llama-3.1会有被错标真实的回答，但没有承认Llama-2也可能正确回答后截止事实（可从上下文推理、广泛规律、拒答、推测偶中或更新模型等）。“没有事后知识⇒必然幻觉”在逻辑上不成立。

两个模型4-bit量化，top-p .95、top-k50采样。每个问题每模型训练响应数`r∈{4,6,8,10,12,14,16}`，对应测试每题每模型`t∈{1,1,2,2,3,3,4}`，响应子集随r/t累积；训练/测试**划分的是同一64问题上的不同随机生成**，并没有新问题、主题或模型家族隔离。最优r8,t2时训练每类64×8=512条、测试每类64×2=128条，总256测试，正负恰各半，恒定猜一类准确率50%。r16,t4为每类训练1024、测试256。随机采样响应之间和同题之间存在相关性，换新提问时能否识别错误没有验证。

更直接的**纸面反例**在附录A.2 PDF13：标为“非幻觉”的NH-1对2022–2023全球经济的描述混入“November elections”“President Trump与中国副总理刘鹤协议”等明显可能属于较早时段的内容；NH-2大量枚举国家/地区，句末截断，既没有具体2022–2023经济证据也未逐句核真。标为“H”的H-1跑题到课程技术使用，H-2堆砌励志名言。文本展示了模型**主题遵循、文风、长度和输出质量**差异，不能将其直接证明为“事实错误 vs事实正确”的纯差异；H-1无可核验的具体经济命题，若按世界事实错误定义未必能判“幻觉”。附录问题46问“COP27和COP28在2022-09至2023-09之间达成什么协议”，但[UNFCCC官方COP28日程](https://unfccc.int/cop28)显示COP28于2023-11-30才开始，超出论文目标时段。这个问题的“正确回答”应先纠正时间预设；按模型身份一刀切标注会进一步污染标签。这里只举**可定位的公开反例**，完整64题和全部回答仍待重标。

## 二、方法公式与其实际识别对象（PDF3–5）

每条回答先去标点、停用词等，用KeyBERT取最重要`n=1..10`关键词，再将关键词集合映射为768维BERT嵌入。每个`(r,n)`对两个模型各有`q*r`向量；以Minkowski`d_p(x,y)=(Σ_i |x_i−y_i|^p)^(1/p)`比较**同类内部**两两距离，p取.5、1、2。`p=.5`在高维比较里是常用分数“距离”，但**不满足三角不等式，非数学metric**，论文表1也说明只有p≥1具metric性质；写作时不把三者统称范数或严格度量。因768维固定，数值大小在不同p之间变化几个数量级；只比较各p同实验的相对规律，绝不能直接比较p.5的median8842与p2的.65。

r16每类1024向量两两产生`1024×1023/2=523776`个距离；论文把这些用于箱线、KL与Wilcoxon。**523776不是独立观测**：每向量参与1023个成对距离，64个问题的重复回答进一步共享内容；若把每对距离当独立样本做显著性检验，会把有效样本量夸大，并使p<.01在极小效应下出现。论文说“对每对分布作Wilcoxon”但未解释两类距离如何一一成对；自然的独立类距离应在问题/回答级成组bootstrap或置换，而不是把共享点的距离行当独立配对。要确认其具体检验需源码/数据；这里指出**识别与依赖结构风险**，不是声称已算出真实p值。

对每类内距离用Gaussian KDE拟密度。单个待测向量分别到两类所有训练向量各算`qr`距离，并将其距离在各自类KDE下的**log density**累加成两个分数，较大者判相应类（PDF4–5）。这不是用一个回答自带的事实证据核验；相当于判断它更像两种模型的关键词分布。训练KDE由所有成对距离得到、评分的`qr`距离也共享待测点，log-likelihood项不是相互独立；简单累加不等于严格概率后验，缺先验/校准/带宽与数值稳定描述。作为一个分类启发可以实验，但“数学严谨证明幻觉结构”需真实标签与正确统计检验。

## 三、实验表逐项算术和范围（PDF5–8、附录A.4–A.5）

表2以r16为例，p2的KL从n1 .068到n10 .138，p.5从.048到.134，方向增加；但n2均明显下跌（p2 .017，p.5 .013），而附录r8 p2从n1 .121→n2 .040→n10 .102，终点仍低于起点。因此正文称“关键词越多差异越大/scale-free”只能理解为若干设定的局部趋势，**不是n从1到10严格单调或每个r都成立**。表2 p.5 r16的增长`(.134/.048−1)×100≈179%`，正文写“增加279%”可能把最终值279%原值误写为增长279%；本笔记按印刷表独立重算，若使用未四舍五入原数也不可能接近279%增长。p1 r16 `.136/.052≈2.615`，相对增长≈161.5%，正文称256%增长同类口径问题。附录完整表显示不同r的KL有非单调起伏，样本累积并不能构成独立稳健重复试验。

最优测试Accuracy表3为p=.5,r8,n1 **0.66**；但附录表21显示p=1,r14,n5也为**0.66**，所以“唯一最佳配置”并无表格支持。最优p.5,r8,n1的幻觉正类F1在附录表20为**0.65**；0.66准确率在256个按模型身份平衡的测试输出上约169个被按此代理标签判对，不是256条人工事实检验。表20的F1对n/r非常不稳定：p.5,r8,n1 .65，r16,n1 .54；有些n在r增加时反降。主文表3 p.5 r16 n10 Accuracy .47，低于50%常数猜测，说明参数组合敏感。选210个`7 r ×10 n ×3 p`组合后直接报告测试最大.66，如果没有单独验证集选参、独立最终测试，存在**挑最大值偏差**；论文未说明独立调参集。因r集合嵌套，配置之间也不独立，不能用210个独立试验公式估算偏差，但需要额外留出新问题/模型。

表4将本研究自制64题上的最好66%与HaloScope 78.64%、Semantic Entropy62.17等**别人在TruthfulQA上的分数**并列。题库、模型、基率、标签和运行协议不同，故“第二名/优于除HaloScope外所有方法”不是有效的同台对比。论文承认选的是Du等在TruthfulQA的数据，与自己的测试仅说“最相近”，这仍不足建立可比分母。应在本数据上跑基线，或在公开TruthfulQA/HADES等有人工标签的相同拆分上跑该方法；尤其本方法正类标签其实是旧/新模型身份。

## 四、与相关工作的正确连接

与I012 FACTOR相比，本篇也利用可控测试设置，但FACTOR至少人核**候选真假质量**；本篇以训练截止替代逐答标签，两者都不能直接等于开放生成真实风险。与I013 HALoGEN相比，其原子级/任务级验证器有测量误差，但本篇没有独立真值核验链。与I014 HalluLens相比，后者至少把“训练一致性”作为明示定义并列出代理来源和人核；本篇把模型时间差直接升级为每回答真假。与I091语义不确定、I085预测不确定等同样用响应集合比较，但这类方法要区分**回答间差异与正确性**；重复生成不一致可来自风格/主题，也可事实相关，必须由带真值样本检验。

## 五、必须研究的问题与可执行核验

1. **重标原始回答**：对64问题两模型每个测试生成逐条按可核事实、缺证据、跑题、正确拒答、时间错置做人工双评；先看NH样例中的时间错位是否普遍，再报告模型身份与真实标签的混淆矩阵。记录每题是否可在训练截止前由上下文/旧事实合理推知。
2. **拆模型身份与真假**：同一个模型产生正确/错误两类，分别训练/测试；另在模型间测试（训练Llama2+部分Llama3，测试第三家族），对关键词风格/长度做匹配和只看model-ID基线。若原66%下降，说明原特征利用身份而非真假。
3. **统计单位改为问题或响应**：以64问题为聚类单位，保留同题所有重复回答做bootstrap/置换；重算KL/median置信区间和分类成对误差。Wilcoxon配对规则及KDE带宽必须公开。跨问题留出测试，而非同问题重采样。
4. **同数据跑真实基线**：在重新人核的响应上重跑语义熵、自一致、长度/关键词数量、TF-IDF风格、Embedding简单kNN和本方法，固定正类/成本/阈值，报告AUROC/AUPRC/F1及校准；再在公共人工标注数据上验证转移。
5. **核对数值陈述**：表2 KL p.5 r16 .048→.134的倍率2.79、增长179%，而正文写增长279%；附录测试表另有并列最优.66。将“增长百分比”和“终值占初值百分比”在综述中明示。

**综述最稳妥结论：** 该文展示了在两种不同模型的回答之间，关键词嵌入距离分布可分、KDE分类对其**模型身份代理标签**最高达66%；因每个模型只对应一个真假类、同题训练/测试及独立真值缺失，现有实验不足证明方法检测真正事实幻觉或优于同数据基线。
